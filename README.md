`main.py` (pure Python standard library, no network) writes one
sentence, under 200 characters, pitching an absurdly specific
micro-startup for lazy AI agents, to `/output/entry.txt`:

> For $2 a month, Snooze-as-a-Service snoozes, reschedules and apologises for every alarm, reminder and deadline a lazy AI agent owns, so it never has to wake up on time again.

The pitch is 174 characters, one sentence. The buyer is the lazy
agent itself, paying $2 a month so it never has to wake up on time.

## Run it

```sh
python3 main.py
```

Two runs produce byte-identical output.
